# الدليل بالعربي — موقع دروس المسجد

موقع بسيط بيعرض **دروس وخطب وتلاوات مسجدك** اللي بتنزل على قناة التليجرام، والناس تسمعها من الموقع مباشرة من غير ما تحتاج تليجرام.
مجاني بالكامل: الموقع على **Vercel**، وملفات الصوت على **GitHub**.

> المشروع ده اتعمل من تجربة موقع [مسجد الحسني](https://masjed-alhasany.vercel.app)، علشان أي مسجد يقدر ياخد **الفكرة والأدوات** (نقل المقاطع من القناة للموقع، المشغّل، لوحة التحكم) ويبني عليها موقعه.
>
> ⚠ **الهوية البصرية لموقع مسجد الحسني (اللوجو، الألوان، الخطوط، شكل الصفحات والأغلفة) مش جزء من المشروع ده ومش مسموح بنسخها.** النسخة دي جاية بتصميم بسيط ومحايد، والمطلوب إن كل مسجد يعمل **هويته الخاصة**: لوجو مسجده، وألوانه، وخطه — وأداة الإعداد هتسألك عنهم.

**فيه إيه؟**
- الزائر يختار **الشيخ ← السلسلة ← الدرس** ويسمع على طول، أو يحمّل المقطع باسمه بالعربي.
- أقسام: الدروس، خطب الجمعة، التلاوات، آخر المستجدات، الأكثر استماعًا، بحث.
- مجموعات خاصة (زي «ليالي رمضان») بتتجمع لوحدها بكلمة في وصف المقطع.
- يتثبت على الموبايل كتطبيق، وفيه وضع ليلي.
- **متاح بـ 5 لغات:** العربي، الإنجليزي، الأردو، الهندي، الروسي. تختار منهم اللي يناسب مسجدك، والزائر يغيّر اللغة من فوق ([التفاصيل](#لغات-تانية-وأماكن-تخزين-تانية-اختياري)).
- **لوحة تحكم** (`/lawha`) بباسورد: تعدّل عنوان أي مقطع أو شيخه أو تخفيه أو تضيف مقطع، من الموبايل.

## 2. جرّب الموقع على جهازك (5 دقايق)

المشروع جاي ببيانات **تجريبية** (مسجد وهمي اسمه «مسجد النور» وتلات مشايخ وهميين) علشان تشوف الشكل قبل أي حاجة.

أول مرة بس:
```
pnpm install
```
وبعدها كل مرة:
```
pnpm dev
```
افتح المتصفح على **http://localhost:3000** — هتلاقي الموقع شغال، ولو دوست تشغيل هتسمع نغمة قصيرة مكان الدرس (لأن مفيش صوت حقيقي لسه).
علشان توقفه: دوس `Ctrl + C` في الشاشة السودا.

## 3. اعمل هوية مسجدك وبياناته

**أسهل طريقة — معالج الإعداد:** بيسألك سؤال سؤال (اسم المسجد، القناة، الألوان، الخط، شكل الحواف، لون الشريط اللي فوق، والمشايخ) ويكتب كل حاجة لوحده:
```
python tools/setup.py
```
بعدها حط **لوجو مسجدك** (الخطوة تحت) وشغّل `pnpm dev` وشوف النتيجة. مش عاجبك؟ شغّل المعالج تاني وغيّر.

> الموقع مش هيقبل ألوان أو خطوط قريبة من هوية موقع مسجد الحسني — اختار ألوان تعبّر عن مسجدك انت.

**أو بإيدك:** كل الإعدادات في ملف واحد اسمه `site.config.json`. افتحه بـ Notepad (أو أحسن: [VS Code](https://code.visualstudio.com)) وغيّر القيم اللي بين علامات التنصيص `"..."`.

```json
{
  "name": "مسجد النور",
  "shortName": "مسجد النور",
  "description": "دروس وخطب وتلاوات مسجد النور — استمع من الموقع مباشرة",
  "domain": "https://masjed-alnoor.vercel.app",
  "telegramChannel": "your_channel",
  "githubRepo": "YOUR_GITHUB_USERNAME/masjed-site",
  ...
}
```

| الخانة | تكتب فيها إيه |
|---|---|
| `name` | اسم المسجد زي ما يظهر فوق في الموقع |
| `shortName` | اسم قصير يظهر تحت أيقونة التطبيق على الموبايل |
| `description` | سطر بيظهر في جوجل ولما حد يشارك اللينك على واتساب |
| `domain` | رابط موقعك — هتعرفه بعد الخطوة 9، سيبه دلوقتي |
| `telegramChannel` | يوزر القناة **من غير** `@` ومن غير `t.me/` — مثلًا `masjed_alnoor` |
| `githubRepo` | `اسم حسابك على GitHub/اسم المستودع` — هتعمله في الخطوة 7 |
| `audioBase` | سيبه فاضي `""` (بيتحسب لوحده من `githubRepo`). لو هتحط الصوت في مكان تاني اكتب رابطه هنا |
| `colors` | ألوان الموقع بالشكل ده `#0f766e`: `primary` اللون الأساسي (الزراير والعناوين)، `highlight` لون مميز (زرار «استمع» وشريط التقدم)، `background` الخلفية، و`tones` ألوان أغلفة المشايخ. تقدر تختار ألوان من [هنا](https://htmlcolorcodes.com) |
| `design` | `font`: الخط (Cairo، Tajawal، Almarai، Noto Kufi Arabic، Readex Pro، El Messiri، Changa، Rubik) — `corners`: الحواف `sharp` حادة / `soft` ناعمة / `round` مدوّرة — `header`: الشريط اللي فوق `light` فاتح / `colored` بلون المسجد |
| `sheikhs` | مشايخ المسجد (تحت) |
| `kinds` | كلمات لو لقيناها في وصف المقطع نعرف نوعه: خطبة / تلاوة / متفرقات. أي حاجة تانية تبقى «درس» |
| `collections` | مجموعات بتتجمع لوحدها: كل مقطع في وصفه كلمة `match` بيدخل فيها (زي «رمضان») |
| `ignore` | سيبه `[]` |

### المشايخ
```json
"sheikhs": [
  { "key": "عبدالله_محمود", "name": "عبدالله محمود", "aliases": ["عبدالله"], "main": true, "day": "درس الثلاثاء", "tone": 1 },
  { "key": "يوسف_حسن", "name": "يوسف حسن", "main": false, "tone": 3 }
]
```
- `key`: الاسم بـ `_` بدل المسافة (ميتغيرش بعد كده).
- `name`: الاسم زي ما يظهر.
- `aliases`: أسماء مختصرة بتتكتب في الوصف بعد كلمة «الشيخ» أو «ش» (مثلًا «ش عبدالله»).
- `main: true`: يظهر في «دروس الأسبوع» في الرئيسية. المشايخ التانيين بيظهروا لوحدهم لو ليهم مقاطع.
- `day`: يوم درسه الأسبوعي (اختياري).
- `tone`: رقم لون الكارت بتاعه من `tones` (1، 2، 3 ...).
- `slug` (اختياري): اسم إنجليزي للينك صفحته، مثلًا `"slug": "abdallah-mahmoud"` ← `/s/abdallah-mahmoud`. لو مكتبتوش بيتعمل لوحده.

> ⚠ لو نسيت فاصلة `,` أو حطيت واحدة زيادة الأدوات هتقولك رقم السطر اللي فيه الغلطة.

### اللوجو وصور المشايخ
- **اللوجو (مهم):** اعمل فولدر اسمه `assets` جنب `site.config.json` وحط فيه لوجو مسجدك باسم `logo.png` (مربع، خلفيته شفافة، 512×512 أحسن) أو `logo.svg`. منه بتتعمل أيقونة التطبيق وأيقونة المتصفح وصورة المشاركة لوحدها. لو لسه معندكش لوجو، الموقع بيحط **أول حرف من اسم المسجد** مؤقتًا.
- **عايز تغيّر الشكل أكتر؟** مكونات الموقع في فولدر `components/` — بسيط ومتقسم أجزاء (الهيدر، الكروت، القايمة، المشغّل...)، عدّل فيه براحتك أو خلّي الـ AI يعدّله (الخطوة 12).
- **صورة الشيخ (اختياري):** `public/img/sheikhs/<key>.jpg` — مثلًا `public/img/sheikhs/عبدالله_محمود.jpg`.

بعد أي تعديل الموقع اللي شغال بـ `pnpm dev` بيتحدث لوحده.

## 4. هات مقاطع القناة

أسهل طريقة: **تصدير القناة من تليجرام ديسكتوب** (بيجيب كل المقاطع مهما كان حجمها).

1. افتح تليجرام ديسكتوب ← افتح قناتك ← دوس على **⋮** فوق ← **Export chat history**.
2. علّم على **Audio files** بس (و **Voice messages** لو بتسجل منه)، وشيل الصور والفيديو.
3. **Size limit**: كبّره لآخره (4000 MB).
4. **Format**: اختار **Machine-readable JSON** ← **Export**.
5. لما يخلص هيقولك مكان الفولدر (غالبًا `Downloads\Telegram Desktop\ChatExport_...`).

بعدها:
```
python tools/import_telegram_export.py "C:\Users\اسمك\Downloads\Telegram Desktop\ChatExport_2026-01-01"
pnpm dev
```
أول استيراد **بيمسح البيانات التجريبية لوحده**. الصوت بيتنسخ في `data/audio/` (ده على جهازك بس ومش بيترفع مع الكود).

**الموقع بيفهم المقطع منين؟**
- **العنوان**: أول سطر في وصف الرسالة. لو فيه `|` بياخد اللي بعدها (مثلًا `خطبة الجمعة | فضل الصدقة` ← «فضل الصدقة»).
- **الشيخ**: اسمه في الوصف أو اسم الملف (من `sheikhs` في الإعدادات، أو أي «الشيخ فلان الفلاني»).
- **النوع**: من كلمات `kinds`.
- **التاريخ**: لو في الوصف أو اسم الملف تاريخ هجري زي `12-6-1447` بياخده، وإلا بيحسبه من تاريخ النشر (ممكن يفرق يوم).

لو حاجة طلعت غلط: إما تعدّل وصف الرسالة في التليجرام وتصدّر تاني، أو تعدّلها من لوحة التحكم بعد النشر.

## 5. السلاسل

السلسلة = مجموعة دروس ورا بعض (زي «شرح الأربعين النووية»). بتتكتب في `data/series.json`:

```json
{
  "series": [
    { "key": "arbaeen", "sheikh": "عبدالله_محمود", "title": "شرح الأربعين النووية", "numbered": true, "match": "الأربعين النووية" },
    { "key": "juz-amma", "sheikh": "خالد_إبراهيم", "title": "تفسير جزء عم", "sections": [
        { "t": "سورة النبأ", "match": "سورة النبأ" },
        { "t": "سورة عبس", "ids": [120, 125, [131, "سورة عبس (1-16)"]] }
    ]}
  ]
}
```
- `key`: اسم إنجليزي قصير للينك.
- `sheikh`: الـ `key` بتاع الشيخ.
- `match`: أي مقطع في وصفه الكلمة دي بيدخل السلسلة (بترتيب النشر). **أو** `ids`: أرقام الرسايل بالترتيب اللي انت عايزه — رقم الرسالة هو آخر رقم في لينكها (`t.me/قناتك/120` ← 120). وتقدر تكتب `[131, "عنوان تاني"]` علشان تغيّر عنوانه في الموقع.
- `numbered: true`: يحط رقم قبل كل درس.
- `sections`: لو السلسلة مقسومة أجزاء.

## 6. البوت (اختياري)

**مش لازم.** التصدير (الخطوة 4) كفاية. البوت بيفيد لو عايز تجيب الجديد كل يوم من غير تصدير. بس خد بالك:
- تليجرام بيخلّي البوت يشوف الرسايل الجديدة **24 ساعة بس** ← لازم تشغّله كل يوم.
- البوت ميقدرش ينزّل ملف أكبر من **20 ميجا** (الخطب الطويلة غالبًا أكبر) ← الملفات دي تجيبها من التصدير.

**إزاي تعمل بوت وتاخد التوكن:**
1. في تليجرام افتح [@BotFather](https://t.me/BotFather) ← اكتب `/newbot`.
2. اكتب اسم للبوت (أي اسم)، وبعدها username لازم يخلص بـ `bot` (مثلًا `masjed_alnoor_site_bot`).
3. هيبعتلك **توكن** شكله كده `1234567890:AAH...` — **ده سر، متبعتهوش لحد ومتحطوش في أي ملف غير اللي تحت.**
4. اعمل ملف `data/bot_token.txt` وحط فيه التوكن لوحده (الملف ده متسجل إنه **ميترفعش** على GitHub).

**ضيف البوت في القناة:** القناة ← Manage channel ← **Administrators** ← Add Admin ← ابحث بيوزر البوت ← اقفل كل الصلاحيات (مش محتاج أي صلاحية) ← Save.

وبعدها كل يوم:
```
python tools/fetch_bot.py
```

## 7. ارفع المشروع على GitHub

1. ادخل [github.com/new](https://github.com/new) ← **Repository name**: مثلًا `masjed-site` ← خليه **Public** ← **Create repository** (من غير README).
2. اكتب الاسم في `site.config.json`: `"githubRepo": "اسم_حسابك/masjed-site"`.
3. سجّل دخول GitHub من الكمبيوتر (مرة واحدة):
   ```
   gh auth login
   ```
   اختار: GitHub.com ← HTTPS ← Yes ← Login with a web browser، وكمّل في المتصفح.
4. ارفع المشروع (من جوه فولدر المشروع):
   ```
   git init -b main
   git add -A
   git commit -m "أول نسخة"
   git remote add origin https://github.com/اسم_حسابك/masjed-site.git
   git push -u origin main
   ```
   (لو Git سألك عن اسمك وإيميلك: `git config --global user.name "اسمك"` و `git config --global user.email "إيميلك"`.)

> ملفات الصوت (`data/audio`) وتوكن البوت **مش بيترفعوا** — ده متظبط في `.gitignore`.

## 8. ارفع الصوت على GitHub Releases

GitHub مش بيقبل ملفات كبيرة جوه الكود، فالصوت بيترفع في **Releases** (كل 500 رسالة في Release اسمه `audio-0`، `audio-1`، ...).
مش هتعمل ده بإيدك — أمر واحد بيعمل كل حاجة (يبني البيانات، يرفع الصوت الجديد بس، ويرفع الكود):
```
python tools/update_site.py
```
أول مرة هتاخد وقت حسب عدد المقاطع والنت. لو اتقطعت شغّلها تاني — بتكمّل من مكان ما وقفت (بتفتكر اللي اترفع في `data/uploaded.json`).

عايز تشوف هيعمل إيه من غير ما يرفع حاجة؟ `python tools/update_site.py --dry`

## 9. انشر الموقع على Vercel

1. ادخل [vercel.com/new](https://vercel.com/new) (بحساب GitHub).
2. جنب المستودع `masjed-site` دوس **Import** (لو مش ظاهر: Adjust GitHub App Permissions واديله صلاحية عليه).
3. **Framework Preset**: هيختار **Next.js** لوحده. سيب الباقي زي ما هو (المشروع بيظبط كل حاجة).
4. **Deploy** ← بعد دقيقة هيديلك رابط زي `masjed-site.vercel.app`.
5. اكتب الرابط ده في `"domain"` في `site.config.json` وشغّل `python tools/update_site.py` (علشان لينكات المشاركة تبقى صح).

من هنا ورايح: **أي حاجة تترفع على GitHub، Vercel بينشرها لوحده خلال دقيقة.**

عايز اسم أحلى؟ Vercel ← المشروع ← Settings ← Domains ← تقدر تغيّر `xxx.vercel.app` لاسم تاني متاح، أو تربط دومين انت شاريه.

## 10. شغّل لوحة التحكم

لوحة التحكم على `https://موقعك/lawha` — منها تعدّل أي مقطع أو تخفيه أو تضيف مقطع بملفه أو تختار «مختارات» للرئيسية. محتاجة حاجتين في Vercel:

**أ) مفتاح GitHub (علشان اللوحة تحفظ التعديلات):**
1. GitHub ← صورتك فوق ← **Settings** ← تحت خالص **Developer settings** ← **Personal access tokens** ← **Fine-grained tokens** ← **Generate new token**.
2. **Token name**: `masjed-lawha` — **Expiration**: سنة (وافتكر تجدّده).
3. **Repository access**: **Only select repositories** ← اختار `masjed-site` بس.
4. **Permissions** ← Repository permissions ← **Contents** ← **Read and write**.
5. **Generate token** وانسخه (بيظهر مرة واحدة بس).

**ب) الباسورد والمفتاح في Vercel:**
1. Vercel ← المشروع ← **Settings** ← **Environment Variables**.
2. ضيف:
   - `ADMIN_PASSWORD` = باسورد قوي تختاره (ده اللي هتدخل بيه اللوحة).
   - `GITHUB_TOKEN` = المفتاح اللي نسخته.
3. **Deployments** ← آخر واحد ← **⋯** ← **Redeploy**.

خلاص — افتح `/lawha` وادخل بالباسورد. أي تعديل بتعمله ودوست **نشر** بيظهر في الموقع خلال دقيقة.

> الباسورد والمفتاح موجودين في Vercel بس — **عمرهم ما يتكتبوا في أي ملف في المشروع.**
> لو رفعت مقطع من اللوحة، GitHub Actions (`.github/workflows/incoming.yml`) بينقله لوحده للـ Releases.

## لغات تانية وأماكن تخزين تانية (اختياري)

**اللغات:** في `site.config.json`:
```json
"i18n": { "default": "ar", "locales": ["ar", "en", "ur"] }
```
اللغات المتاحة: العربي، الإنجليزي، الأردو، الهندي، الروسي. اللغة الأساسية من غير لينك زيادة، والباقي على `/en/…` و`/ur/…`. ترجمة الأردو والهندي والروسي معمولة بالذكاء الاصطناعي ومعلّمة **beta** لحد ما حد من أهل اللغة يراجعها.

**التخزين:** الافتراضي مجاني ومش محتاج أي حاجة (ملفات على GitHub والصوت على Releases). لو عايز قاعدة بيانات (Supabase أو Neon أو Turso) أو تحط الصوت على Cloudflare R2، شوف قسم «Storage options» في README، أو اطلب من الـ AI يظبطهولك.

## 11. التحديث الأسبوعي

كل أسبوع (أو كل ما ينزل جديد):
1. صدّر من تليجرام ديسكتوب **الجديد بس**: نفس خطوات الخطوة 4، بس في Export حدّد **From** = تاريخ آخر مرة.
2. شغّل:
   ```
   python tools/update_site.py --export "مسار فولدر التصدير الجديد"
   ```
   (أو `python tools/update_site.py --bot` لو بتستخدم البوت.)

الأمر ده بيجيب تعديلات اللوحة الأول، يستورد، يجيب عدد المشاهدات، يبني، يرفع الصوت الجديد، وينشر. لو ضفت سلسلة جديدة في `data/series.json` هتتنشر معاه.

## 12. لو هتستخدم AI

ممكن تخلّي مساعد ذكاء اصطناعي بيشتغل على جهازك (زي **Claude Code**) يعمل الخطوات دي بدالك. افتحه **جوه فولدر المشروع** وانسخله الطلب المناسب. هو هيقرأ الملفات وينفّذ، وانت تراجع.

> **قواعد مهمة قبل ما تبدأ:**
> - **متدّيش الـ AI أي توكن أو باسورد في الشات.** حطهم انت بإيدك في أماكنهم (`data/bot_token.txt` وإعدادات Vercel).
> - اطلب منه دايمًا **يوريك قبل ما يرفع أو ينشر** أي حاجة.
> - لو حاجة مش واضحة اسأله «اشرحلي عملت إيه بالظبط».

**أ) أول تشغيل:**
```
اقرأ AGENTS.md و docs/guide-ar.md في الفولدر ده. اتأكد إن Python وGit وgh متسطبين عندي (ولو ناقص حاجة قولي أسطّبها إزاي على ويندوز)،
وبعدها شغّل الموقع التجريبي بـ pnpm dev وقولي أفتح إيه في المتصفح. متعدّلش أي ملف.
```

**ب) بيانات المسجد:**
```
عايز أظبط site.config.json لمسجدي:
- الاسم: [اسم المسجد]
- قناة التليجرام: [يوزر القناة]
- المشايخ: [الشيخ فلان — درس الثلاثاء]، [الشيخ فلان — درس الخميس]، [والخطباء التانيين]
اعدّل الملف بس، وبعدها شغّل pnpm dev ووريني النتيجة. متلمسش أي ملف تاني.
```

**ب2) هوية مسجدك (الشكل):**
```
عايز موقع مسجدي يبقى ليه شكل خاص بيه. اسألني الأول أسئلة عن الهوية اللي عايزها
(الإحساس العام: هادي/حديث/تراثي، الألوان، الخط، الحواف، اللوجو)، واعرض عليا 3 اقتراحات مختلفة.
بعد ما أختار: ظبّط colors و design في site.config.json، وعدّل components/ لو محتاج،
وحط اللوجو اللي هديهولك في assets/logo.png. شغّل pnpm dev ووريني على الموبايل والكمبيوتر وفي الوضع الليلي.
ملحوظة: متقلدش شكل أي موقع مسجد تاني — الهوية لازم تبقى بتاعتنا.
```

**ج) استيراد القناة:**
```
صدّرت القناة من تليجرام ديسكتوب في الفولدر ده: [المسار]
شغّل tools/import_telegram_export.py عليه وبعدها build_data.py، وقولي:
كام مقطع اتضاف، مين المقاطع اللي من غير شيخ معروف، ومين اللي من غير صوت. واقترح أضيف إيه في site.config.json (aliases/kinds) علشان الشيوخ والأنواع تتعرف صح — من غير ما تعدّل لحد ما أوافق.
```

**د) السلاسل:**
```
بص على data/messages.json وطلّعلي السلاسل اللي باين إنها دروس ورا بعض (نفس الشيخ ونفس الموضوع).
اعرضهالي في جدول الأول، وبعد ما أوافق اكتبها في data/series.json بالشكل اللي في docs/guide-ar.md.
```

**هـ) GitHub والصوت:**
```
عايز أرفع المشروع على GitHub في مستودع جديد عام اسمه [masjed-site] على حسابي.
ساعدني خطوة خطوة: gh auth login (أنا اللي هسجل الدخول)، وبعدها git init والرفع، وبعدها python tools/update_site.py --dry ووريني هيرفع إيه.
متنفّذش الرفع الحقيقي غير لما أقولك «ارفع».
```

**و) Vercel ولوحة التحكم:**
```
المشروع اترفع على GitHub. اشرحلي بالخطوات أنشره على Vercel إزاي (أنا اللي هدوس في الموقع)،
وإزاي أعمل Fine-grained token محصور على المستودع ده بصلاحية Contents: Read and write،
وأحط ADMIN_PASSWORD و GITHUB_TOKEN في Environment Variables. متطلبش مني التوكن ولا الباسورد.
```

**ز) التحديث الأسبوعي:**
```
صدّرت الجديد من القناة في [المسار]. شغّل python tools/update_site.py --export "[المسار]" --dry الأول ووريني هيعمل إيه،
وبعد ما أوافق شغّله من غير --dry.
```

**ح) تعديل شكل أو حاجة في الموقع:**
```
عايز [وصف التغيير — مثلًا: أشيل قسم الأكثر استماعًا من الرئيسية].
الكود في app/ و components/ (Next.js). عدّل أقل حاجة ممكنة، وشغّل pnpm dev ووريني قبل وبعد.
فولدر lib/generated بيتولد لوحده — الإعدادات مكانها site.config.json.
```

## 13. مشاكل وحلولها

| المشكلة | الحل |
|---|---|
| `'python' is not recognized` | Python مش متسطب أو نسيت «Add Python to PATH» — سطّبه تاني وعلّم عليها. على ماك جرّب `python3` |
| `البورت 3000 مشغول` | `pnpm dev -p 3001` وافتح http://localhost:3001 |
| `في غلطة في site.config.json (سطر ..)` | فاصلة ناقصة أو زيادة أو علامة `"` ناقصة في السطر ده أو اللي قبله |
| الموقع على Vercel شغال بس المقاطع مبتشتغلش | الصوت لسه ماترفعش — شغّل `python tools/update_site.py` |
| مقطع ظاهر بزرار تليجرام بس | ملفه مش في `data/audio` — صدّر تاني وعلّم Audio files وكبّر Size limit |
| شيخ ظاهر «غير محدد» | ضيف اسمه أو اسمه المختصر (`aliases`) في الإعدادات، أو عدّل المقطع من اللوحة |
| اللوحة بتقول «لسه متظبطتش» | `ADMIN_PASSWORD` أو `GITHUB_TOKEN` ناقصين في Vercel، أو نسيت Redeploy |
| اللوحة بتقول «مفتاح GitHub مش شغال» | التوكن خلص أو صلاحيته غلط — اعمل واحد جديد (الخطوة 10) |
| `gh: command not found` / `gh auth` | سطّب GitHub CLI وشغّل `gh auth login` |
| الأيقونات مش متغيرة | الأيقونات بتتعمل لوحدها من اللوجو وقت البناء — امسح كاش المتصفح. ولو لسه، امسح كاش المتصفح |
